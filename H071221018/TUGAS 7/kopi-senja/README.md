# Kedai Kopi Senja

Aplikasi pemesanan mandiri berbasis React dan Vite.

## Teknologi

- React
- JavaScript JSX
- Vite
- Tailwind CSS
- React Hooks (useState)
- Props

## Fitur

1. Menampilkan 9 menu.
2. Filter kategori menu.
3. Melihat detail menu.
4. Status ketersediaan menu.
5. Menambahkan dan mengurangi pesanan.
6. Menghitung jumlah dan total harga.
7. Form nama pelanggan dan nomor meja.
8. Validasi pemesanan.
9. Notifikasi pesanan berhasil.
10. Reset keranjang setelah transaksi.
