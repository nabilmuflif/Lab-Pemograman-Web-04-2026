# Pustaka Senja

Website katalog perpustakaan komunitas
menggunakan Next.js App Router dan Tailwind CSS.

## Teknologi

- Next.js
- React
- JavaScript JSX
- Tailwind CSS
- Next.js App Router
- React Hooks (useState)
- Next Link
- Next Navigation (usePathname)

## Fitur

1. Navbar dan Footer bersama.
2. Navigasi halaman menggunakan Next Link.
3. Penanda halaman aktif.
4. Hamburger menu responsive.
5. Halaman Beranda.
6. Statistik koleksi buku.
7. Katalog sembilan buku.
8. Filter kategori.
9. Fitur favorit.
10. Dynamic Routing halaman detail buku.
11. Validasi ID buku.
12. Formulir usulan buku.
13. Validasi formulir.
14. Daftar usulan buku.

## Instalasi

npm install

## Menjalankan aplikasi

npm run dev

## Alamat

http://localhost:3000
